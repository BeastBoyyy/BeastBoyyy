# Profile README Setup

Your GitHub profile README appears when you create a public repository named exactly:

```txt
BeastBoyyy
```

Then add these files to that repository:

```txt
README.md
.github/workflows/snake.yml
```

After pushing the files, open the repository's Actions tab and run `Generate contribution snake` once. The animated snake may take a minute to appear because it is published to the `output` branch.

The GitHub connector in this session is authenticated as `BeastBoyyy`, but no repositories are currently installed or accessible to it, so I could not publish the files directly from here.
